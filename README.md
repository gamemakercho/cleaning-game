# 도서관 청소 게임

모바일 브라우저에서 실행하는 정적 웹 게임입니다. 화면을 드래그해 고양이를 움직이고, 와다다 버튼으로 넓은 범위를 청소하세요.

## GitHub Pages로 실행하기

1. GitHub에서 Public 저장소를 만들고 README 추가를 선택합니다.
2. Add file → Upload files에서 이 폴더 안의 파일과 assets 폴더를 모두 올립니다. index.html은 저장소 최상위에 있어야 합니다.
3. 커밋을 main 브랜치에 저장합니다.
4. Settings → Pages에서 Source를 Deploy from a branch, Branch를 main, 폴더를 /(root)로 선택하고 Save를 누릅니다.
5. 배포가 완료되면 Pages에 표시되는 Visit site 링크로 접속합니다.

assets 폴더의 이름과 파일 이름을 유지하세요. .nojekyll은 기본 정적 파일 배포를 위한 빈 파일입니다.

## 데이터 사용량

게임이 처음 읽는 이미지와 코드의 파일 크기 합계는 7,151,275바이트(약 7.2MB)입니다. 실제 전송량은 압축, 브라우저 캐시, HTTP 부가 정보에 따라 달라집니다.

화면 이동, 애니메이션, 점수 계산, 다시 플레이는 브라우저에서 처리합니다. 같은 페이지에서 재시작할 때 게임 서버에 추가 데이터를 요청하지 않습니다. 다시 접속하거나 새로고침할 때의 전송량은 캐시 상태에 따라 달라집니다.

별도의 설치, 데이터베이스, API 키가 필요하지 않습니다.
